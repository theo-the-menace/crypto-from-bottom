# Crypto From Bottom

A book-style, practice-first curriculum for people who are new to crypto and want to build durable skills instead of chasing signals.

> Educational material only. Crypto is volatile; derivatives and leverage can lose money quickly. Start with observation, paper trading, and strict risk limits.

## How to use this book

Read Chapter 1 without placing a trade. Re-draw the diagrams, annotate historical charts, and answer the exercises at the end. Only then move to a written strategy specification. The goal is to understand what a button, chart, or number means before risking money on it.
